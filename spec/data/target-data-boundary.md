# 突合対象プロジェクトのデータ境界

Thaleia は対象プロジェクトの名前に依存せず、リポジトリを変更せずに使える。
対象を足すたびにコード・仕様・コミットを増やさない。

## 対象の渡し方

- 突合の対象は実行時の入力だけで指定する (Praeforma のプロジェクト ID・Anatomia のプロジェクト ID)。
- 対象ごとの登録記録・突合結果・評価は `THALEIA_DATA_DIR` (未設定ならリポジトリ同梱の `data/`) にだけ置く。
  `data/` 配下は `.gitkeep` 以外をすべて git 管理外にする。非公開タイトルを扱う環境では
  `THALEIA_DATA_DIR` をリポジトリの外に向ける。

## リポジトリに書かないもの

- 対象プロジェクトの名前・コード名・ID・リポジトリ名・パス。
- 対象から得た仕様の本文、ドメイン名、突合の件数や結果。
- これらはコミットの件名と本文、PR の本文、`spec/`・`tests/`・fixture にも書かない。
  テストの fixture は架空の名前と ID で作る。

## 変更してよいもの

対象によらず働く汎用の変更だけをリポジトリに入れる (クライアントの不具合修正、突合ロジック、
入出力の形式)。ある対象で見つかった不具合も、対象を伏せた一般的な説明で記録する。
